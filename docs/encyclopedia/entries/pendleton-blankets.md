# Pendleton & trade blankets
Updated: 2026-10-12 · Sources: craigslist 1321 photos (pink satin-bound twin blanket, 1950s label); eBay sold pattern (knowledge 2024–25); Pendleton label dating guides

## What it is / how to recognise it in a photo
Pendleton Woolen Mills (Oregon). Money is in the JACQUARD TRADE BLANKETS: bold geometric Native-inspired patterns (Chief Joseph, Harding, Beaver State), felt binding, "Beaver State" label = 1920s–50s. Plain solid bed blankets with satin/sateen binding (pink, blue, camel) are common and cheap. Also valuable: Pendleton "Glacier Park" stripe (cream w/ 4 stripes), Hudson's Bay 4-point/6-point stripes (England, ivory with green/red/yellow/indigo), Cabin Craft, Oregon City trade blankets (pre-1930, rare). Sellers write "Pendleton wool blanket", "Indian blanket", "camp blanket".

## What sellers usually miss
The pattern name and the Beaver State / early labels; moth damage photos; size (queen > twin).

## Shipping / handling
3–6 lb, $15–20 each way. eBay/Etsy.

## Buy rule
Buy when: jacquard Pendleton/HBC with vintage label ≤ $80 and no moth holes. Pass when: solid satin-bound over $25, or binding/holes need sewing. Profit must be ≥ max($50, price).
