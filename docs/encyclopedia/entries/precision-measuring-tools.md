# Precision measuring tools (Starrett, Mitutoyo, Brown & Sharpe, Lufkin)
Updated: 2026-10-12 · Sources: eBay sold (agent knowledge Oct 2026)

## What it is / how to recognise it in a photo
Micrometers, dial/digital calipers, dial indicators, squares, height gauges, often in fitted wooden/plastic boxes. Brand is etched on the frame. Machinists' estate "tool lots" on Craigslist are where these hide under a $40–100 "tools" title.

## What sellers usually miss
Brand in a crowded tool-box photo; gauge block sets look like a wooden box of steel squares. Snap-on/Mac mechanics tools are a different (well-known) market – sellers always name them.

## Shipping / handling
1–10 lb, $10–30. eBay; machinists buy fast.

## Buy rule
Buy when: Starrett/Mitutoyo/B&S set or box visible in a lot priced ≤ 30 % of its resale. Pass when: single calipers/mics (margin < $50), "didital calipers" no-name. Profit must be ≥ max($50, price).
