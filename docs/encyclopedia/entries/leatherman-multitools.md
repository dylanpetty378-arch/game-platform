# Multi-tools (Leatherman PST, Wave, Charge; Victorinox; Gerber)
Updated: 2026-10-12 · Sources: knowledge of eBay sold ranges; no dated comp pulled

## What it is / how to recognise it in a photo
Leatherman PST (1983–2004): plain stainless, no blade lock, "Leatherman Tool / Portland OR" stamp – the original; early 1980s "Pat. Pend." versions and ones with the original leather sheath are collected. Modern Wave+/Charge+/Surge sell $60–120 used; Skeletool $35–50. Victorinox SwissTool $50–80. Gerber MP600 $30–45. Collector money is in discontinued/limited: Leatherman Charge TTi, Wave 2004 first run, Skeletool CX in colours, 25th anniversary PST.
