# Vintage player-endorsed baseball gloves
Updated: 2026-10-12 · Sources: keymancollectibles.com (Rawlings Mickey Mantle gloves, 1964 Big Leaguer youth $50–100), eBay.de 176956534257 (Rawlings Mantle DF1 11.5" excellent, ask $120), craigslist 1394 photos

## What it is / how to recognise it in a photo
1940s–70s store-model gloves with a facsimile player signature stamped in the palm/pocket and a model number (Rawlings: MM, MM5, MM9, MMF, DF1, XPG; Wilson A2000 series; Spalding; MacGregor). Rawlings "Personal Model" or "Professional Model" and "Made in USA" on the back. Sellers write "old baseball mitt", "<player> glove", "vintage Rawlings glove".

## What sellers usually miss
The model number and the signature in the palm; "Professional Model" vs youth; USA-made; original box multiplies value. Craigslist sellers often DO name the player — then price is usually fair.

## Shipping / handling
1–2 lb, $10–12 each way. eBay. Condition (lacing, cracking, writing) drives price more than player.

## Buy rule
Buy when: Mantle/Mays/Clemente/Koufax USA-made pro model ≤ $40, or boxed example ≤ $100. Pass when: youth models, repaired lacing, or price ≥ $45 for DF1/MMF class. Profit must be ≥ max($50, price).
