# Signed costume jewelry (Boucher, Sherman, Trifari, Eisenberg, Hobé, HAR, Schiaparelli)
Updated: 2026-10-12 · Sources: collectingcostumejewelry101.com (2024 value revisit of Mayer collection), eBay/Etsy listings Oct 2026, agent knowledge

## What it is / how to recognise it in a photo
Rhinestone/enamel brooches, sets (parure = brooch + earrings + necklace), cuff links. Value is in the **signature stamped on the back** – ask for a back photo. Sellers who list "signed Boucher" know the name but usually price off old book values, which are below 2024 market for the best makers.
Tells: Boucher = "BOUCHER" or Phrygian-cap mark + 4-digit inventory no. (post-1955); Marboux = Boucher's lower line; Sherman (Canada) = script "Sherman", Swarovski stones, japanned or rhodium; Eisenberg = "Eisenberg Original/Ice", big stones; Trifari = crown-T (Crown Trifari 1950s = the good era); HAR = oriental/genie figurals; Hobé = double-struck mark, sterling; Schiaparelli = script signature, lava/moulded glass; Juliana/DeLizza & Elster = unsigned, 5-link construction, open backs; Weiss, Lisner, Coro, Sarah Coventry, Avon, Napier, Monet = common ($10–40).

## What sellers usually miss
The back. "Vintage brooch lot" photos of fronts only – ask for backs. Unsigned Juliana is identified by construction (5-link, figure-8 puddling), not a mark. Bakelite is a separate category (test with Simichrome).

## Shipping / handling
Ounces; $5 first-class. eBay or Etsy; photograph on black velvet.

## Buy rule
Buy when: Boucher/Eisenberg/Hobé/HAR/Schiaparelli/Haskell signature visible and price ≤ 30 % of tier; Sherman parures under $50. Pass when: Avon/Coventry/Monet lots, unsigned rhinestone "lots", or front-only photos. Profit must be ≥ max($50, price).
