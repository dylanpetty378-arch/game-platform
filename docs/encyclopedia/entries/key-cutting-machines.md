# Vintage key cutting machines (Curtis Clipper, Ilco, HPC)
Updated: 2026-10-12 · Sources: eBay listings for Curtis Clipper Model 15 w/ cams & carriages (search 2026-10); craigslist 987; locksmith forum references

## What it is / how to recognise it in a photo
Curtis Clipper Model 14/15: hand-lever code cutter in a cast body, with interchangeable CAMS (numbered discs, e.g. DM-3, VW-3) and CARRIAGES (key holders) in a wooden or metal case; used for cutting automotive keys by code for 1930s–80s cars. Also Ilco/HPC duplicators (motor + cutter wheel). Sellers write "key machine", "key cutter", "locksmith tool".

## What sellers usually miss
Cams and carriages are the value; the body is cheap. Count them.

## Shipping / handling
10–25 lb, $25–45 each way. eBay to locksmith/classic-car buyers.

## Buy rule
Buy when: complete-ish Clipper (≥ 20 cams) ≤ $120. Pass when: body + a few carriages at $100+. Profit must be ≥ max($50, price).
