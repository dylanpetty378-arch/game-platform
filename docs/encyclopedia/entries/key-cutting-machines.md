## What it is / how to recognise it in a photo
Curtis Clipper Model 14/15: hand-lever code cutter in a cast body, with interchangeable CAMS (numbered discs, e.g. DM-3, VW-3) and CARRIAGES (key holders) in a wooden or metal case; used for cutting automotive keys by code for 1930s–80s cars. Also Ilco/HPC duplicators (motor + cutter wheel) and Cole National (e.g. 3K commercial machine) duplicators. Code machines (HPC 1200 "Blitz", Framon) use code cards/settings rather than tracing a key. Sellers write "key machine", "key cutter", "locksmith tool".

## Makers, brands and variants
- **Curtis Industries** – Clipper Model 14/15 (hand code cutters); cams and carriages are model-specific and individually collectible/useful.
- **Ilco (Ilco Unican)** – duplicators (e.g. 045, Ilco Unican Speed series; general knowledge, verify).
- **HPC** – 1200 code machine ("Blitz"), with code cards; Speedex/Punch machines (general knowledge, verify).
- **Framon** – code machines, prized by locksmiths.
- **Cole National** – 3K commercial duplicator (hardware-store machines).
- Value lies in completeness: cams, carriages, code books, cases.

## Materials, finishes and quality tells
Cast-iron/steel bodies with machined slides; cams and carriages stamped with codes; original wooden/metal fitted case. Quality tells: smooth lever action, sharp cutter, crisp cam numbers. Motorized duplicators: motor runs, cutter wheel and tracer aligned. (general knowledge, verify)

## Condition, damage and repairs
Missing cams/carriages (the main value), worn or chipped cutters, rust on slides, frayed cords on motorized units, missing code books/cards. Ask for a count of cams and carriages and photos of their stamps; for motorized units, whether it runs.

## Fakes, reproductions and reissues
None meaningful. Watch for married lots (cams from different machines) – check they fit the model. (general knowledge, verify)

## Market
Locksmiths, classic-car restorers (code-cut keys for old cars) and tool collectors. eBay is the main venue; parts (cams/carriages) sell steadily individually. Low volume, slow for bare machines. (general knowledge, verify)

## What sellers usually miss
Cams and carriages are the value; the body is cheap. Count them.

## Shipping / handling
10–25 lb, $25–45 each way. eBay to locksmith/classic-car buyers. Remove/secure cams and carriages separately; pad the cutter.

## Selling it (for the buyer-facing listing)
State make/model, number and list of cams and carriages (with codes), case, code books/cards, working status. Photograph each cam/carriage stamp, the machine body plate, the case. Title keywords: "Curtis Clipper 15 key code machine cams carriages", "locksmith", "classic car keys".

## Buy rule
Buy when: complete-ish Clipper (≥ 20 cams) ≤ $120. Pass when: body + a few carriages at $100+. Profit must be ≥ max($50, price) after ~13% fees and shipping both ways (Dylan's rule). Fits a passenger seat.
