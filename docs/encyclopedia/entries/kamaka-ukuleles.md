# Kamaka ukuleles (extends vintage-ukuleles)
Updated: 2026-10-12 · Sources: Reverb listing 1950s–60s gold-label Kamaka soprano; Mahar's Vintage Guitars HF-1 white label (sold); Elderly HF-1 new price; southernukulelestore 1960s Kamaka

## What it is / how to recognise it in a photo
Honolulu-made solid koa ukes. Headstock decal "Kamaka / Hawaii" with the double-K logo; pre-1970 "gold label" inside the soundhole (1950s–69), "white label" 1970s–2000s, current ones have a dated label. Pineapple-shaped body = Kamaka Pineapple (1920s patent, reissued). HF-1 soprano, HF-2 concert, HF-3 tenor. Sellers usually know the name but not the era.

## What sellers usually miss
Gold vs white label (era). Anyone who writes "Kamaka" has already priced it as a Kamaka.

## Shipping / handling
3–4 lb in case; $25–35 insured. Reverb 5–8% + payment, eBay 13%.

## Buy rule
Buy when: any genuine Kamaka ≤ $250 crack-free, or gold-label ≤ $450. Pass when: seller lists "Kamaka" with tiered pricing (they know), or any crack/separation. Profit must be ≥ max($50, price) after fees and shipping both ways (Dylan's rule).
