# LEGO bulk lots & sealed sets
Updated: 2026-10-12 · Sources: craigslist 1478 (large collection $80), 1561 (Lego/K'nex $50), 1857 (Tower Bridge modular $170), 1218 (Ninjago shrine new $100); BrickLink / eBay sold pattern (knowledge 2024–25)

## What it is / how to recognise it in a photo
Bulk bins: value by weight (eBay sold ~$8–12/lb clean sorted, $5–7/lb mixed with junk) plus MINIFIGURES (the real value: licensed Star Wars/Marvel figs $3–30 each, some $100+). Sealed/retired sets: check set number on the box against BrickLink. Retired big sets (Modulars 10xxx, UCS Star Wars, Tower Bridge 10214) run $200–600 used complete, more sealed. Sellers write "Lego lot", "tote of Legos", "Lego collection", "by the pound".

## What sellers usually miss
Minifigs in the tote (Star Wars especially); retired set numbers; "Lego" that is actually Mega Bloks.

## Shipping / handling
Heavy — 20 lb tote ≈ $30–45 each way; only worth it if figs/sets visible. eBay/BrickLink.

## Buy rule
Buy when: price ≤ $3/lb with visible licensed minifigs, or retired set ≤ 40% of BrickLink used. Pass when: price ≥ $5/lb bulk, current retail sets, or mixed brands. Profit must be ≥ max($50, price).
