# Christmas dinnerware (Spode Christmas Tree, Waechtersbach, Lenox Holiday, Johnson Bros)
Updated: 2026-10-12 · Sources: eBay listings Oct 2026 (Waechtersbach Christmas Tree plates), eBay sold memory 2025

## What it is / how to recognise it in a photo
Spode Christmas Tree (green-banded, tree with presents, England – the most common and most liquid); Waechtersbach Christmas Tree (West Germany, bright red rim, square-ish plates, red/white checker box); Lenox Holiday (ivory w/ holly, gold rim); Johnson Brothers Merry Christmas; Pfaltzgraff Winterberry; Fitz & Floyd figural. Seller words: "Christmas dishes", "holiday china set", "Xmas plates".

## What sellers usually miss
Brand – listed as "Christmas dishes $40". Serving pieces (Spode tureen, 3-tier server) are where the margin is; plates alone are freight-heavy.

## Shipping / handling
A 20-pc set is 20+ lb and fragile – $35–50 to ship and 30 min packing. Sell local (FB Marketplace, no fee) or part out servers on eBay.

## Buy rule
Buy when: Spode/Waechtersbach/Lenox set ≤ $25 locally, or serving pieces ≤ $15 each. Pass when: must ship a full plate set – margin is gone.
