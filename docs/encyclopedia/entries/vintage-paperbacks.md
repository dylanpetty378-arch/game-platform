# Vintage paperbacks (Signet/Bantam/Pocket/Ace, 1940s–60s)
Updated: 2026-10-12 · Sources: eBay sold memory 2025, Signet Fleming series knowledge

## What it is / how to recognise it in a photo
Mass-market paperbacks with painted or photo covers; publisher logo and catalogue number on cover top (Signet D2052 etc.). Value drivers: first paperback printings (check copyright page "First Printing" with no later printing listed), pulp cover art (Avon, Popular Library, Ace Doubles), GGA ("good girl art"), early sci-fi/horror (Ace Doubles, Ballantine), Fleming Signet first printings with the Barye Phillips/Hooks covers. Seller words: "vintage paperbacks", "James Bond books", "pulp".

## What sellers usually miss
Printing statement. "Original Ian Fleming collection 70 years old" is almost always 1960s Signet 10th+ printings.

## Shipping / handling
Media mail, 14 books ~6 lb, $8. eBay 13%.

## Buy rule
Buy when: 1st-printing statement visible or pre-1955 pulps in VG at ≤ $3/book. Pass when: 1960s reprint runs priced ≥ $50 – profit evaporates.
