# 1980s laser-tag toys (Photon, Lazer Tag)
Updated: 2026-10-12 · Sources: eBay product page 1424492925 (Photon phaser target game, parts, $7); 2warpstoneptune.com Lazer Tag/Photon archive; agent knowledge of eBay sold bands (verify); run12 sheet 57

## What it is / how to recognise it in a photo
Entertech/LJN **Photon** (1986): grey-and-red pistol phaser, chest/back sensor pod, helmet; "Photon" in italic script. Worlds of Wonder **Lazer Tag** (1986): white-and-red StarLyte pistol, StarSensor chest unit, StarHelmet, StarCap; later the "Starlyte Pro" rifle. Both rarely complete and rarely working (NiCd/contacts corrode).

Nothing – both brands are always named. Only buy sealed/boxed working sets cheap.

## Shipping / handling
2–4 lb per set, bulky helmets – $15–25 each way.

## Buy rule
Buy when: boxed complete working set under $40. Pass when: loose untested units at $50+ each (6850). Profit must be ≥ max($50, price).
