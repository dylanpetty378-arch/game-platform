# Snap-on vintage toolboxes and hand tools
Updated: 2026-10-12 · Sources: eBay sold listings KRA-series boxes and vintage ratchets 2025; collector knowledge

## What it is / how to recognise it in a photo
Red steel top chests with a script "Snap-on" nameplate (1940s–60s have a raised script badge; later a rectangular logo). Model stamped on a plate inside (KRA-53, KRA-55, K-60 etc.). Hand tools: "Snap-on" stamped on shank with a date code letter. Collectors chase 1930s–50s boxes in clean original paint, and old ratchets (No. 71, RS-series "Speed").

## What sellers usually miss
Age (script badge = 1950s or earlier) and that clean original paint is worth 2x a repaint.

## Shipping / handling
Boxes 40–60 lb – freight/UPS $60–120, pack risk high; realistically local-sale items. Hand tools ship for $8–12.

## Buy rule
Buy when: script-badge box in clean paint ≤ $100 and buyer is local; hand tools only in lots under $5/tool. Pass when: rusty/dented, or any box that must ship. Profit must be ≥ max($50, price) after fees and shipping both ways (Dylan's rule).
