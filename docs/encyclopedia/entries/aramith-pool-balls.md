# Pool balls (Aramith) and billiard accessories
Updated: 2026-10-12 · Sources: knowledge of eBay sold ranges and Aramith retail (Premium set ~$200–230 new, Super Pro ~$320 new); no dated comp pulled

## What it is / how to recognise it in a photo
Belgian phenolic balls; the box or the cue ball says "Aramith". Lines by value: Crown Standard (budget, ~$110 new), Premium (~$220), Super Pro / Tournament ($300+), Black (~$400). Fakes: generic "Vigma/Iszy" sets with the same colours sell for $40 new – look for the Aramith logo on the cue ball and the moulded box. Used Premium sets sell $100–150 if unchipped; a yellowed/chipped set $40–60.

## What sellers usually miss
The line (Premium vs Super Pro). Sellers who say "Aramith" already know; the arbitrage is a photo of a Super Pro set in a listing titled "pool balls".

## Shipping / handling

## Buy rule
Buy when: Super Pro/Tournament set under $60 or Premium under $35. Pass when: Premium at $75 (sold ~$120 → profit <$50). Profit must be ≥ max($50, price).
