# DeArmond guitars (Fender/Guild reissues, 1998–2003)
Updated: 2026-10-12 · Sources: equipboard.com (M-75T spec, Korea 1998–99, used avg $600), creamcitymusic.com (M-75 w/ hardshell, sold $599), reverb listings M-66 / M-77T; craigslist listing 1146 photos

## What it is / how to recognise it in a photo
Fender-owned Guild sub-brand, 1998–2003, reissuing 1960s Guild shapes. "DeArmond" script on headstock; back of headstock says "Crafted in Korea" (1998–2000, better, set-neck, Bigsby on T models) or "Crafted in Indonesia" (2000–03, cheaper bolt-on, chrome covered pickups). Models: M-75 / M-75T (single-cut, 2 pickups, Bigsby on T), M-77T, M-72, M-65, M-66 (solid), Starfire / X-155 / X-135 (hollow), Jet-Star, Pilot basses. Sellers write "DeArmond", "Guild DeArmond", "Fender DeArmond".

## What sellers usually miss
Korea vs Indonesia; Bigsby T models; hardshell DeArmond case adds $60–80. Sellers often list as "starter guitar" or in a bundle with a practice amp.

## Shipping / handling
Guitar in hardshell ~15 lb, $50–75 each way (UPS). Fees 13% eBay / 8% Reverb. Shipping both ways eats ~$120, so needs a ≥ $300 spread.

## Buy rule
Buy when: Korean M-75T/M-77T/X-155 ≤ $200, or Indonesian M-75 w/ case ≤ $120. Pass when: Indonesian over $150, missing case, bundles padded with amps. Profit must be ≥ max($50, price).
