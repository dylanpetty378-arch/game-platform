# Boss compact pedals (and other common used stompboxes)
Updated: 2026-10-12 · Sources: Reverb price guide pattern (knowledge 2024–25); craigslist 1182 (CE-3), 1578 (OD-1 housing), 1098 (SD Tweak Fuzz), 1400 (Skreddy Rubber Soul), 1352 (Supro 1303), 1134 (Kasleder Albatross)

## What it is / how to recognise it in a photo
Boss: the rectangular compact with hinged pedal and thumbscrew battery door. Model name on the front (CE-2, OD-1, DS-1, SD-1, DM-2, CE-3…). Flip it: silver thumbscrew + "Made in Japan" on the bottom label (1977–~1990, "black label"/"silver label") vs black thumbscrew + "Made in Taiwan" (later, cheap). Sellers write "Boss pedal", "chorus pedal", "overdrive pedal", often with the model.

## What sellers usually miss
Japan vs Taiwan; silver screw; the model letters (CE-2 vs CE-3 is 2×); "Dimension C"; original box. Craigslist musicians usually DO know the model — margins are thin unless the seller misreads Japan/Taiwan.

## Shipping / handling
<1 lb, $6–9 each way. Reverb (fees ~8%) beats eBay.

## Buy rule
Buy when: MIJ CE-2/OD-1/DM-2/SD-1-silver ≤ $70, VB-2/DC-2 ≤ $150, boutique ≤ 40% of Reverb used. Pass when: Taiwan-era, housing-only, or seller already quotes Reverb price. Profit must be ≥ max($50, price).
