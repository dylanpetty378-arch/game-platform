# Harmonicas (Hohner Marine Band, Chromonica, pre-war)
Updated: 2026-10-12 · Sources: knowledge of eBay sold ranges; no dated comp pulled

## What it is / how to recognise it in a photo
Hohner (Germany) dominates. Modern Marine Band 1896 ~$45 new, so used ones are $15–25. Money is in: pre-war Marine Bands with the "Hohner trademark" star/medals cover and wood comb in original box ($40–100), Chromonica 270/280 and Super 64 ($80–200), 1990s limited editions in gold/wood display boxes (Marine Band 100th Anniversary 1896–1996 gold-plated set ~$60–120 if complete with box/certificate), and Hohner Echo/Auto-Valve tremolos in boxes.
