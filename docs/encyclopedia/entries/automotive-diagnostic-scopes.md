# Automotive diagnostic scopes & engine analysers (Snap-on Counselor, Sun, Allen)
Updated: 2026-10-12 · Sources: eBay product page 1930423042 (Snap-on MT3000 Counselor II – active asks $495–695, cart $1,995); garagejournal.com ignition-scope thread; gmt400.com "Vantage" thread.

## What it is / how to recognise it in a photo
Red-and-black Snap-on cabinet on a steel cart with a green CRT screen and keypad: MT1665 Counselor (1980s), MT3000 Counselor II (1990s), MT2500 Scanner (hand-held red brick), Vantage/Vantage Pro (hand-held graphing meter). Sun 1015/1115 and Allen Smart Engine Analyzers are grey roll-around towers. Sellers write "Snap-on oscilloscope", "engine analyzer", "diagnostic machine".

## What sellers usually miss
Model number is on the rear plate. Working MT3000s with the full lead set ask $500+, but these are 80–120 lb cabinets on carts: freight $200+ kills any arbitrage unless the buyer is local.

## Shipping / handling
Cabinet units: local pickup only (freight $200–350). Hand-helds (MT2500, Vantage, Solus) ship in a 5-lb box for $15–20.

## Buy rule
Buy when: hand-held Snap-on scanners (MT2500 w/ cartridges, Solus, Vantage) ≤ $60 and tested. Pass when: any CRT cabinet unit (freight, untested electronics – Dylan's rule). Profit must be ≥ max($50, price) after fees and shipping both ways.
