# Vintage home computers (1977–1990)
Updated: 2026-10-12 · Sources: dfarq.homeip.net (MC-10 value article, Sept 2024), eBay listings Oct 2026, agent knowledge

## What it is / how to recognise it in a photo
Beige/brown keyboard-computers in or out of original box. Model number is printed on the box and on a label under the unit (Radio Shack cat. no. 26-xxxx; Commodore / Apple / Atari model names).

## What sellers usually miss
"Tandy computer" / "old Radio Shack computer" with no model; the 16K RAM module (26-3013) in the box roughly doubles MC-10 value. Apple II-series and Amiga are the ones to stop for.

## Shipping / handling
Boxed MC-10 ~4 lb ($15); C64/Apple II with PSU 10–20 lb ($30–50). Untested electronics break Dylan's rule unless the seller demonstrates power-on.

## Buy rule
Buy when: Apple II family, Amiga, SX-64, Model 100 shown working, under $100. Pass when: MC-10, TI-99, Atari 400/800XL, VIC-20, anything untested. Profit must be ≥ max($50, price).
